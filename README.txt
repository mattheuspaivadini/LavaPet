==================================================
                 LAVAPET
==================================================

Sistema de gestão para pet shop (LavaPet) refatorado
para execução autônoma em memória (sem dependências
de banco de dados externo ou db4o).

Conteúdo:
- Dados pré-carregados automaticamente ao iniciar
- Modelos: Tutor, Pet e Servico
- Utilitário: BancoMemoria (repositório em memória)
- Consolas de execução:
  * Demonstracao.java (Menu interativo completo)
  * Listar.java (Listagem de tutores, pets e serviços)
  * Deletar.java (Operações de exclusão em cascata)
